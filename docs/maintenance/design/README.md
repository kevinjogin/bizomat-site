# Maintenance field release: design records

Working records for the Maintenance additions with MEX as a functional reference (owner, 20 Nov 2026: "start the
Maintenance additions using MEX now"). MEX is a reference only: no MEX name, screen, text or data goes into the product.

- `mex-gap-analysis.json`: what the MEX field app's modules do (from its help guide: Work Orders and Inspections,
  Requests, Stocktakes, Readings, Edit Mode), what BIZOMAT Maintenance does today (mapped from the code), the gap list
  with a recommended scope, and two independent checks of it (claims against the code, coverage of MEX).
- `field-release-design.json`: the detailed designs of the release's work streams (A: lists, asset context, requests
  and dashboard; B: parts, reservations, requisitions and stocktakes; C and D follow).

These are design inputs, not a description of what is built: `docs/maintenance/README.md` says what is live.
