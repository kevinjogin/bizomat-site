# CAD Automation in BIZOMAT ERP: end-to-end test results, 20 Nov 2026

The owner's decision 1 of the audit (`docs/cad/AUDIT-2026-11-20.md`): a local end-to-end run and a production pilot on
the owner's own company, in place of staging (retired 20 Nov 2026). This is the local run. It is the security,
migration and performance part of the brief's Part 10 deliverables, before the pilot.

## What ran

| Part | What |
| --- | --- |
| BIZOMAT ERP | The real work app from this branch (`apps/work`, built with `npm run build`, run on Node as production runs it), with its own empty SQLite database and every migration to 0039 |
| CAD Automation | The real engine from kevinjogin/bizomat-cad, branch `claude/festive-wozniak-xkypzl` (contract 2), over HTTP |
| Computers | The stand-in Companion (bizomat-cad `tests/bridge_fakes.py`): pairs with its own key, verifies every signed command, answers as SOLIDWORKS would. No real SOLIDWORKS |
| People | A company owner, an employee and a read-only member of one registered company, and the owner of a second company |
| Flags | Switched in the test's own database only: `cad_in_erp` for both companies, `cad_products`, then `cad_redirect` and `cad_password_retired` on and off, and `cad_in_erp` off for the rollback |

The test is kevinjogin/bizomat-cad `tests/test_erp_e2e.py` (slow, run by hand before a release):

```bash
BIZOMAT_WORK_APP=<bizomat-site>/apps/work BIZOMAT_E2E_REPORT=report.txt python -m pytest -m slow tests/test_erp_e2e.py
```

## Performance (Part 9, test 14)

The CAD Automation screen is its own chunk, loaded only when someone opens it: 157 KB (34 KB compressed), with no 3D
code. The ERP's first page does not load it (its entry script is 293 KB, 88 KB compressed, unchanged by this work).
Page load times were not measured in a browser.

- Production data: the migration report (accounts linked and to review) comes from the console's CAD Automation panel
  once the engine of contract 2 is deployed.
- Bill of materials proposals, drawings on orders and quality records, and malformed uploads: covered by the unit tests
  with a stand-in engine (`apps/work/test/cad.test.ts`) and the engine's own tests, not end to end.
- Test 4 (company switch with unsaved changes) does not apply: there is no CAD editor in the browser. Test 12 (script
  sandbox) does not apply: no user scripts run on the server.
